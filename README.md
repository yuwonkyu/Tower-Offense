# Tower-Offense

> **자동 전투 + 로그라이크 카드 + 실시간 공성** — 5분 안에 적 타워를 부숴라.

워크래프트3 유즈맵 "타워 서바이벌"의 **역방향** 컨셉. 방어가 아닌 공격, 살아남기가 아닌 부수기. 모바일 하이브리드 캐주얼 장르(Archero, Survivor.io, 뱀파이어 서바이벌)의 손맛을 잇는 실시간 공성 전략 게임.

---

## 🎮 핵심 컨셉

| | |
|---|---|
| **장르** | 자동 전투 / 로그라이크 / 공성 전략 |
| **플랫폼** | 모바일 (Android / iOS) |
| **세션 길이** | 5분 (예정) — 배속 4x 시 약 1분 15초 |
| **수익 모델** | IAA + IAP 하이브리드 |
| **타깃** | 짧고 강한 빌드 메이킹을 즐기는 캐주얼 ~ 미드코어 |

---

## 🎯 코어 루프

```
스테이지 전투
   ↓ 적 유닛 처치 & 경험치 획득
레벨업 → 카드 선택 (로그라이크 빌드 성장)
   ↓ 타워 파괴
보상 (금화 / 다이아) → 유닛·영웅 영구 강화
   ↓
다음 스테이지 도전
```

---

## ⚔️ 시스템 한눈에 보기

### 유닛 (5종)
방패병 · 활병 · 창병 · 투석기 · 검사 — 자동 생성, 자동 전투

### 영웅 (3종)
- **마루한** — 돌격대장 (탱커형, 광역 스탯 버프 스킬)
- **미르** — 궁사 (광역 화살비)
- **노을** — 암살자 (순간 이동 + 광역 피해 + 디버프)

레벨업 시 선형 성장, HP 25% 회복. 사망 시 90초 부활.

### 카드 시스템
- **슬롯 8개** (유닛 특성 + 글로벌 버프 혼합)
- 같은 카드 5번 → Lv1~Lv5 강화
- 등급: 일반 / 고급
- 풀 고갈 시 → 골드 / 다이아 **획득 카드** 등장 (재화 보상)

### 난이도
- **일반 모드** — 기본
- **하드 모드** — 일반 10스테이지 클리어 시 개방. 난이도·보상 2배, 카드 선택지 +1, 랜덤 디버프

---

## 💰 수익화

**IAA + IAP 하이브리드** (2026 모바일 캐주얼 표준)

- **IAP** — 다이아·금화 패키지, 영웅 구매, 입장권, (예정) 배틀패스 / 시작 패키지
- **IAA** — 입장권, 재도전, 보상 2배, 무료 재화, 카드 재선택, 일일 버프
- **IAA + IAP** — 4배속(광고 OR 유료), 광고 한도 초과 시 다이아로 추가 시청
