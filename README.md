# Tower-Offense

> **자동 전투 + 로그라이크 카드 + 실시간 공성** — 5분 안에 적 타워를 부숴라.

워크래프트3 유즈맵 "타워 서바이벌"의 **역방향** 컨셉. 방어가 아닌 공격, 살아남기가 아닌 부수기. 모바일 하이브리드 캐주얼(Archero, Survivor.io, 뱀파이어 서바이벌)의 손맛을 잇는 실시간 공성 전략 게임.

---

## 🎮 한눈에 보기

| | |
|---|---|
| **장르** | 자동 전투 / 로그라이크 / 공성 전략 |
| **플랫폼** | 모바일 (Android / iOS) |
| **세션 길이** | 5분 (테스트 후 확정) — 배속 4x 시 약 1분 15초 |
| **수익 모델** | IAA + IAP 하이브리드 |
| **출시 시점 컨텐츠** | 인간 종족 30 스테이지 (일반/하드) |
| **장기 비전** | 8 종족 × 30 스테이지 = **240 스테이지** + 시리즈 확장 |

---

## 🎯 코어 루프

```
영웅 단독 등장 (2.5D 중앙 타워)
   ↓ 적 유닛 처치 & 경험치 획득
레벨업 → 카드 선택 (8슬롯 빌드 구성)
   ↓ 적 영웅·미니보스·타워 파괴
보상 (금화 / 다이아) → 유닛·영웅 영구 강화
   ↓
다음 스테이지 도전
```

## ⚔️ 전투 시스템

### 화면
- 2.5D 중앙 타워 / 영웅 360° 주변에 유닛 자동 생성
- 이펙트 최소화, **공격 사운드 중심**
- 타워 외관 4단계 변화 (100/60/30/0%) — 프로토타입은 색상만

### 유저 측 — 영웅 3종
| 영웅 | 컨셉 | 액티브 스킬 |
|---|---|---|
| **마루한** | 돌격대장 (탱커 / 광역) | **투신** — 모든 스탯 % 증가 |
| **미르** | 궁사 (원거리) | **살소나기** — 광역 화살비 (150%) |
| **노을** | 암살자 | **피노을** — 순간이동 + 광역(130%) + 공격력 디버프 |

레벨업 시 선형 성장, HP 25% 회복, 공속 성장 O. 사망 시 90초 부활.

### 유저 측 — 유닛 5종
| 유닛 | 공/방/HP | 사거리 | 컨셉 |
|---|---|---|---|
| 방패병 | 2/40/60 | 1 | 근접 탱커 |
| 활병 | 24/5/40 | 20 | 원거리 |
| 창병 | 27/17/50 | 3 | 중근거리 |
| 투석기 | 45/35/90 | 45 | 광역 공성 |
| 검사 | 20/25/50 | 1.5 | 근거리 |

### 피해 공식 (전 게임 공통)
```
실제피해 = 공격력 × (100 / (100 + 방어력))
```

### 유닛 우선타깃 시스템
- 기본: 범위 내 가까운 적
- **투석기** → 탱커 우선
- **암살자 / 기마병** → 원거리 우선
- **폭탄병** → 밀집 위치
- **치유사** → 공격 X, HP 낮은 아군 회복

## 🃏 카드 시스템

### 룰
- **슬롯 8개** (유닛 + 특성 + 글로벌 버프 통합)
- 같은 카드 5번 뽑으면 Lv1 → Lv5 (MAX)
- **선택 시간 30초** / 미선택 시 3장 중 랜덤
- 일반 75% / 고급 25% (하드 70/30)
- 슬롯 가득 차면 **기존 카드 강화만 가능**

### 카드 비주얼
| 단계 | 비주얼 |
|---|---|
| Lv1~4 | 실버 프레임 |
| Lv5 MAX | **골드 프레임 + MAX 텍스트** |
| 카드 풀 고갈 후 골드/크리스탈 카드 | 골드 프레임 |
| 카드 조합 (후속 업데이트) | **프리즘 이펙트** |

### 보너스
- **MAX 도달 시** → 다음 카드 선택권 1회 추가
- **5% 확률** 매 선택 시 한 번 더 뽑기 발동
- **스택 캡 없음** — 회피/크리 100%+ 가능 (먼치킨 빌드 허용)

### 카드 종류
| 종류 | 개수 | 설명 |
|---|---|---|
| 유닛 카드 | 5 | 뽑으면 유닛이 영웅 주변 360° 랜덤 생성 시작 |
| 유닛 특성 카드 | 25 (5×5) | 보유 유닛 강화. 미보유 유닛 카드는 풀에서 자동 제외 |
| 글로벌 버프 카드 | 17 (일반 10 + 고급 7) | 전체 / 영웅 / 유닛 강화 |
| **총 42장** | | 풀 고갈 시 골드 / 다이아 획득 카드 등장 |

### 빌드 패스 3종
1. **순수 영웅형** — 글로벌 버프만 8슬롯 → 영웅 솔로 캐리
2. **유닛 군대형** — 유닛 5종 + 특성 → 학살
3. **하이브리드** — 영웅 강화 + 유닛 1~2종 집중

## 🏰 적 측 시스템

### 적 영웅 — 타워 위 고정 (HP = 타워 HP 동기화)
| 영웅 | 담당 스테이지 | 컨셉 | 스킬 |
|---|---|---|---|
| **기사** | 1~10 | 종족의 얼굴, 균형형 | 성주변 휩쓸기 (광역, 쿨 20s) |
| **마법사** | 11~20 | 비전(지식 탐구) | 필드 랜덤 메테오 5발 (쿨 30s) |
| **팔라딘** | 21~30 | 기사 + 신성력 종합 | 신성 광역 + 회복 오라 + 무적기 |

### 적 측 신규 유닛 (인간 종족 확장)
| 유닛 | 등장 | 컨셉 |
|---|---|---|
| 하급 마법사 | 11+ | 매직미사일 (단일) |
| 중급 마법사 | 18+ | 매직볼 (광역) — 하급 점차 사라짐 |
| 상급 마법사 | 25+ | 체인 라이트닝 3회 튕김 — 중급 점차 사라짐 |
| 암살자 | 14+ | 회피 30%, 원거리 우선 |
| 폭탄병 | 18+ | 자폭 (자폭 전 EXP 100% / 후 50%) |
| 치유사 | 21+ | 공격 X, 아군 회복 = 공격력 × 0.5/초 |
| 기마병 | 24+ | 빠른 기동, 원거리에 취약 |

### 타워 HP 곡선 (1 → 30)
- 1 스테이지: **1,000 HP / 방어 0**
- 10 스테이지: 12,000 / 15
- 20 스테이지: 45,000 / 40
- 30 스테이지: **100,000 HP / 방어 70**
- 감속형 곡선 (1→30 = **100배**)

### 구조물 — 파괴 가능 + 경험치 보상
| 구조물 | 배치 | 효과 |
|---|---|---|
| **성벽** | 타워 주변 고정 | 타워 진입 차단 |
| **바리케이트** | 맵 전체 랜덤 | 동선 방해 |
| **트랩** | 타워 주변 랜덤 | 발동 시 1초 기절 + 80% 피해 |

> 디버프 / 공격형 / 파괴 불가 구조물은 50+, 100+ 스테이지에서 등장 예정.

### 적 유닛 = 디아블로식 대량 학살
- 5분 누적: 150 ~ 1,500 마리
- 매 스테이지 다른 조합 (`[13. 스테이지 패턴](docs/design/13-stage-patterns.md)` 참고)
- 25 스테이지부터 **미니 보스** (다운그레이드 영웅) 10초 쿨로 스폰
- 30 스테이지 **팔라딘 최종 보스** = 1분/3분 2회 직접 등장 (처치 EXP 100)

## 🎚️ 난이도

### 일반 모드
1~30 스테이지. 30클리어 = 1차 엔딩.

### 하드 모드
- **일반 N클리어마다 하드 (N-9)~N 스테이지 10개 해금**
- 타워 HP **× 2**, 적 유닛 스펙 **+20%**
- 보상 2배, 카드 선택지 +1, 랜덤 디버프

### 무한 모드 / 30+ 스테이지
- 무한 모드는 별도 컨텐츠로 분리 예정
- 31+ 일반/하드는 **추후 종족 추가 패치**로 확장

## 💰 수익화 (IAA + IAP 하이브리드)

### IAP
- 다이아 / 금화 패키지
- 유닛 뽑기, 영웅 구매, 입장권
- (예정) 배틀패스, 시작 패키지, 성장 패키지

### IAA (리워드 광고 트리거)
| 시점 | 보상 |
|---|---|
| 카드 선택 | 리롤 1회 추가 / 카드 +1장 표시 |
| 영웅 사망 | 즉시 부활 (1판 1회) / 부활 시간 50% 감소 |
| 스테이지 시작 전 | 랜덤 일반 카드 1장 보유 / 유닛 생성속도 +20% |
| 스테이지 종료 후 | 보상 2배 / 재도전 / 다이아 카드 확정 등장 |
| 4배속 | 영구 사용 가능 |

### IAS (광고 제거 구독)
- **월 $2~3** 권장
- 인터스티셜 광고 제거 + 4배속 영구 무료 해금

### 광고 빈도 관리
- 인터스티셜: 3스테이지마다 1회
- 일일 리워드 광고 한도: 20회
- 한도 초과 시 다이아 5개로 1회 대체 (IAA → IAP 전환)

## 🌍 종족 시스템 비전 (장기 로드맵)

### 8 종족 + 4 라이벌 구도

| 종족 | 컨셉 | 라이벌 |
|---|---|---|
| **인간** | 균형, 직업 다양 | 마족 (삶 vs 죽음) |
| **마족** | 비균형, 극과 극 (마물/언데드/다크엘프 포함) | 인간 |
| **엘프** | 4원소 자연친화 + 체력재생 | 드워프 (자연 vs 기술) |
| **드워프** | 기술 + 화력 + 높은 방어 | 엘프 |
| **용족** | 기본 스탯 압도적 (진화의 정점) | 수인족 |
| **수인족** | 변신 기믹 (시간 경과 시 강화) | 용족 |
| **거인족** | 초탱커, 광역 분쇄 | 천계 (타이탄 vs 신화 영웅) |
| **천계** | 빠른 공/이속 + 회복/버프 | 거인족 |

### 종족별 디버프 매핑
- 인간: 덫 (DOT) / 마족: 저주 (스탯↓) / 엘프: 얽힘 (슬로우) / 드워프: 폭발 트랩 (스턴)
- 용족: 공포 / 수인족: 출혈 / 거인족: 위압 / 천계: 회복 차단

### 확장 가능 규모
- **240 스테이지** / **64~80 유닛** / **24 영웅** / **8 디버프**
- 종족 길드 / 동맹전 / 스토리 모드 / 시리즈 확장 가능

## 📊 메타 시스템

### 보상
```
최종 금화 = 유닛 처치 점수 + 클리어 시간 점수
         + 스테이지 클리어 점수 + 획득 경험치 점수
         + 이벤트/유료 보너스
```

### 다이아 획득 경로
업적 / 퀘스트 / 수집 도감 / 출석 / 상점 / 광고

### 영구 강화 (홈에서 금화 사용)
- 유닛 공/방/HP (이속·사거리는 고정)
- 영웅 스킬 계수 (기본 10% + 레벨당 +2%)

## 🚧 현재 단계

**설계 단계 — 약 90% 완료, 프로토타입 진입 직전**

### 남은 설계 항목
- [ ] 스테이지별 클리어 타임 시뮬레이션 (5분 vs 10분 결정)
- [ ] 경험치 곡선 시뮬레이션 (신규 유닛 EXP 반영)
- [ ] 추가 스탯 도입 여부 (체력재생/흡혈 등 글로벌 카드)
- [ ] 메타 시스템 수치 (업적/퀘스트/도감 보상)

### 핵심 강점
- 자동 전투 + 직접 개입 + 짧은 세션 → 모바일 친화
- 로그라이크 카드 빌드 다양성 (3가지 패스)
- 디아블로식 학살감 + 8 종족 장기 확장성
- 광고/IAP 하이브리드로 F2P/결제 모두 만족
