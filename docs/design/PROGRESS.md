## 전투 AI 룰 (2026-06-12 시뮬레이션으로 확정)

여러 교착/붕괴 패턴을 시뮬레이션으로 잡아가며 확정한 규칙:

- **아군 유닛 = 공성군**: ① 사거리 내 적 교전(우선타깃 점수) → ② 사거리 내 구조물 포격
  → ③ 성벽(자기 섹터)/타워로 진군. 먼 적 추격 금지 — 피격 시 반격(retaliate)으로만 응전
  (추격 허용 시 스폰 스트림에 전선이 묶여 타워에 영영 도달 못 함)
- **랠리 웨이브**: 아군 유닛 30마리 이상 모이면 진군 시작 — 1마리씩 적 캠프에 갈리는 것 방지
- **적 유닛 = 방어군** (설계 10): 타워 반경 60 안의 아군만 추격, 없으면 타워 링(+8) 귀환
  — 맵 횡단 추격 금지 (아군 거점/영웅이 초반에 압살당하던 문제 해결)
- **영웅 = 거점 사수**: 단독 타워 돌진 금지, 탐지 35 내 적만 교전
- **성벽 섹터 차단**: 성벽은 자기 방위각 섹터(π/배치수)만 차단 — 남쪽 성벽을 부수면
  남쪽 진입로 개방 (모든 성벽 파괴 강제 X)
- **피격 반격**: 구조물/타워 공격 중(또는 무타깃) 피격 시 공격자로 타깃 전환
- **시간 경과 EXP 초당 1**: 처치 0 데스 스파이럴에서도 레벨/카드가 돌게 하는 안전망 (컴백 메커니즘)

## 프록 카드 시스템 (2026-06-12 구현 + 재측정)

- 구현: 도발(공격 시 주변 적 타깃 전환) / 관통(근처 1마리 추가 타격) / 추가타·불화살(공격력 %
  고정 추가피해, 방어 미적용) / 출혈·화상(3초 DoT, 최대체력 %/초 — 타워·구조물 미적용) /

  생존, 쿨타임) — `hurt()` 중앙화로 피해감소·불굴이 모든 피해 경로(스킬/트랩/DoT 포함)에 적용

  성장으로 보정 전제. 메타 포함 재측정 필요
