### 2026-06-11
- **스테이지 제한시간**: 10분 확정 (x2 무료 / x4 유료)
- **배속 초기값**: 플레이어 마지막 선택값 유지
- **유닛 해금**: 적 신규 유닛 첫 등장 스테이지 클리어 시 자동 해금
- **다이아 뽑기**: 미해금 유닛도 포함, 첫 획득 시 해금 + 정보 팝업
- **추가 스탯**: 기본값 0, 카드로만 증가 (회피/크리 등)
- **앱 재개**: 강제 종료/백그라운드 전환 → 재개 불가 / 짧은 부재 → 재개 가능
- **경험치 곡선**: `필요 누적 EXP(레벨 L) = (L-1) × (10L + 50)`
  - 10분 기준 스테이지 20 → 약 레벨 31, 스테이지 30 → 약 레벨 40
- **유닛 카드 강화**:
  - 카드 필요량 = `min(999, round(2 × (n/2)^1.59))`
  - 금화 필요량 = `min(100000, round(200 × (n/2)^1.59))`
  - 최대 100레벨, 레벨당 기초 스탯 +1%
- **영웅 레벨 시스템 (A안)**:
  - 영웅별 독립 레벨 (사용한 영웅에 EXP 적립)
  - EXP: 스테이지 클리어 + 중복 영웅 뽑기 전환
  - 레벨업 시 스탯 포인트 +1, 5레벨마다 스킬 포인트 +1
  - 스탯 초기화: 다이아 소모
- **홈 화면**: 하단 탭 (홈 / 영웅 / 유닛 / 상점)
- **전투 HUD 확정**: `docs/design/16-battle-hud.md` 참고
- **카드 선택 UI**: TFT(롤토체스) 스타일, 30초 타이머, 미선택 시 랜덤
- **스테이지 종료 정산**: 처치수 / 사망수 / EXP / 금화 / 클리어 시간 / 도달 레벨
- **광고 제거 = 평생 1회 결제** (월 구독 폐기) — 광고 제거 + x4 영구 해금
