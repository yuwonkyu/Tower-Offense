# 04. 카드 시스템 — 유닛 특성 카드

## 규칙
- 유닛 1마리당 특성 카드 **5종**
- 같은 카드 5번 뽑으면 **Lv1 → Lv5** 강화
- 등급: **일반** / **고급** (희귀도 차등 적용)
- **타워·구조물에는 % 피해형 특성 미적용** (출혈, 화염 등)

|---|---|---|
| 일반 | 체력 증가 | 8 / 16 / 24 / 32 / 40% |
| 일반 | 체력 회복 | 초당 0.5 / 1 / 1.5 / 2 / 2.5% |
| 일반 | 방어 강화 | 8 / 16 / 24 / 32 / 40% |
| 일반 | 이동 속도 증가 | 5 / 10 / 15 / 20 / 25% |

| 등급 | 특성 | Lv1 / 2 / 3 / 4 / 5 |
|---|---|---|

> 버서커의 즉사 위험은 **글로벌 카드(불굴)** 로 해소.

## 설계 원칙 요약
1. **일반 % 스탯**: 8 / 16 / 24 / 32 / 40% (선형 +8)
2. **고급 효과**: 빌드 정의급 수치 (더 가파른 곡선)
3. **출혈/화염**: 타워·구조물 미적용 (유닛 한정)
4. **버서커 방어감소 상한**: -95% (즉사 방지)
5. **CC 최대치**: 기절 1.2초 (긴 CC 회피)
