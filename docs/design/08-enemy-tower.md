# 08. 적 측 정의 — 타워 (F-1)

## 타워 기본 정의
- **공격 X** — 타워 자체는 샌드백
- **HP / 방어력만 보유**
- 타워 앞에 **적 영웅 + 방어 유닛** 배치
- 타워 파괴 = 스테이지 클리어

## 피해 공식 (전체 게임 공통)
```
실제피해 = 공격력 × (100 / (100 + 방어력))
```

| 방어력 | 피해 비율 | 감소율 |
|---|---|---|
| 0 | 100% | -0% |
| 10 | 91% | -9% |
| 30 | 77% | -23% |
| 60 | 62% | -38% |
| 100 | 50% | -50% |

> 후반 방어력 인플레이션에도 게임이 깨지지 않는 모바일 표준 공식.

## 곡선 구간 특성
| 구간 | 컨셉 | 적 영웅 |
|---|---|---|
| 1~10 | 학습 구간 (완만한 가속) | 1번 영웅 |
| 11~20 | 본격 도전 (배율 가속) | 2번 영웅 |
| 21~30 | 엔드게임 (풀빌드 요구) | 3번 영웅 |

10스테이지마다 적 영웅 변경 → 새 컨셉 / 새 스킬 / 새 스탯.

## 하드 모드 타워 스펙
- **HP × 2 (일반의 2배)**
- 방어력 동일
- 보상 2배 + 카드 선택지 +1 + 랜덤 디버프

예시) 하드 1스테이지: 2,000 HP / 0 방어력

## 30 스테이지 이후
- **일반 30스테이지 클리어 = 일반 모드 1차 엔딩**
- 30 이후 추가 스테이지는 **추후 업데이트**로 추가
- **무한 모드**는 별도 모드로 운영 (게임 종료 후 정의)
