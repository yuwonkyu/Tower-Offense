# 07. 카드 시스템 룰 (E)

## 카드 등장 룰

| 항목 | 룰 |
|---|---|
| 선택지 수 (일반 모드) | **3장** |
| 선택지 수 (하드 모드) | **4장** |
| 선택 제한 시간 | **30초** |
| 미선택 시 처리 | 3장 중 **랜덤 자동 선택** |
| 희귀도 출현 확률 (일반) | 일반 75% / 고급 25% |
| 희귀도 출현 확률 (하드) | 일반 70% / 고급 30% |
| 가중치 | **완전 균등** (모든 카드 동일 확률, 첫 등장 포함) |

## 카드 풀 관리 룰

| 상황 | 처리 |
|---|---|
| 카드 5렙 (MAX) 도달 | 풀에서 **자동 제외** |
| 슬롯 8개 가득 참 | **신규 카드 등장 X**, 슬롯 내 카드만 강화 가능 (뱀서 방식) |
| 미해금 유닛의 특성 카드 | 풀에서 자동 제외 |
| 풀 완전 고갈 시 | 골드 카드 / 낮은 확률 다이아 카드 등장 |

## 리롤 (다시 뽑기)
| 종류 | 비용 | 횟수 |
|---|---|---|
| 무료 리롤 | - | 1판당 1회 |
| 광고 리롤 | 광고 1회 | +1회씩 누적 |
| 다이아 리롤 | 5다이아 | 무제한 |

## 첫 등장 보장
**없음** — 랜덤성과 빌드 다양성 유지

## 스택 캡 (회피/크리 등)
**캡 없음** — 카드 누적 시 100% 이상도 가능. 게임의 재미를 위한 먼치킨 빌드 허용.

## 카드 비주얼 등급

| 단계 | 비주얼 | 조건 |
|---|---|---|
| 일반 (Lv1~4) | **실버 프레임** | 기본 카드 |
| MAX (Lv5) | **골드 프레임** + "MAX!" 텍스트 | Lv5 완성 시 |
| 카드 풀 고갈 시 골드/크리스탈 카드 | **골드 프레임** | 풀 고갈 후 등장 |
| 조합 카드 (후속 업데이트 예정) | **프리즘 이펙트** | 향후 카드 조합 시스템 |

## MAX 도달 보너스
- **추가 카드 1회 즉시 획득** (다음 카드 선택권 1회 추가)
- 별도 EXP 보너스 없음

## 5% 보너스 카드 선택
- 매 레벨업 카드 선택 시 **5% 확률로 카드 한 번 더 뽑기 발동**
- 발동 시: 신규 3장 등장 → 1장 추가 선택
- 컨셉: 가끔 보너스로 통쾌한 진행감

# 광고 통합 설계 (Ad-Aware Design)

## 3대 원칙
1. **흐름을 끊지 않는다** — 인터스티셜은 스테이지 전환 시점만
2. **유저가 보고 싶게 만든다** — 보상이 명확하고 매력적
3. **결제 유저는 보상이 더 크다** — 광고 < IAP 가치

## 리워드 광고 트리거 포인트

### 인게임 (전투 중)
| 시점 | 보상 |
|---|---|
| 레벨업 카드 선택 | 리롤 1회 추가 |
| 레벨업 카드 선택 | 카드 +1장 추가 표시 (4장 중 선택) |
| 영웅 사망 시 | 즉시 부활 (1판 1회 한정) |
| 영웅 사망 시 | 부활 시간 50% 감소 (무제한) |

### 스테이지 시작 전
| 시점 | 보상 |
|---|---|
| 스테이지 진입 화면 | 시작 시 랜덤 일반 카드 1장 보유 |
| 스테이지 진입 화면 | 유닛 생성속도 +20% (해당 판) |

### 스테이지 종료 후
| 시점 | 보상 |
|---|---|
| 클리어 보상 화면 | 보상 2배 |
| 실패 화면 | 재도전 (체력/시간 50% 회복 상태) |
| 카드 풀 고갈 후 | 즉시 다이아 카드 확정 등장 |

## 인터스티셜 광고 (전면 광고)
- **트리거**: 스테이지 클리어 → 보상 화면 진입 시, 홈 복귀 시
- **빈도**: 3스테이지마다 1회 (피로도 방지)
- **금지 시점**: 전투 중, 카드 선택 중, 결제 화면

## 광고 빈도 관리
- 일일 리워드 광고 한도: **20회**
- 한도 초과 시 → **다이아 5개로 1회 광고 대체** (IAA → IAP 전환)

## 광고 제거 구독 (IAS)
- **월 $2~3** 권장
- 효과:
  - 인터스티셜 광고 제거
  - 리워드 광고는 유지 (자발적 시청)
  - **4배속 영구 무료 해금** 포함
- 라이트 결제 유저 진입점 + 매출 안정화

## 광고 설계 가이드라인
- 카드 시스템 광고 보상은 **빌드를 가속**하되 **빌드를 결정짓지 않음**
- 리롤·추가 표시는 선택지를 늘려주는 방향
- 결제 vs 광고 시청 격차: 광고는 **편의/가속**, IAP는 **영구적 성장**
