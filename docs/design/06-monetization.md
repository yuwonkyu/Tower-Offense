# 06. 수익화 전략

## 채택 패러다임: IAA + IAP 하이브리드
2023~2026 모바일 캐주얼/하이브리드 캐주얼 사실상 표준.
참고 사례: Archero, Survivor.io, 뱀파이어 서바이벌.

## 용어
- **IAP** — In-App Purchase (단건 결제)
- **IAA** — In-App Ads (광고 시청 보상)
- **IAS** — In-App Subscription (구독)

## 광고 제거 = 평생 1회 결제 (확정)
- 월 구독이 아닌 **1회 결제 평생 적용** (buyout)
- 효과: 인터스티셜 광고 제거 + 4배속 영구 해금
- 의도: 라이트/단기 유저도 부담 없이 지르는 구조. 가격은 출시 전 결정 (참고: $7~15 구간)

## 이미 반영된 구조
| 카테고리 | 항목 |
|---|---|
| IAP | 다이아 / 금화 이중 재화, 다이아·금화 구매, 유닛 뽑기, 영웅 구매, 입장권 구매 |
| IAA | 입장권 / 재도전 / 보상 2배 / 무료 금화·다이아 / 카드 재선택 / 일일 버프 |
| IAA + IAP | 4배속 = 광고 OR 유료 |

## 추가 검토 권장
- **배틀패스** (월 단위 $5~10) — 하이브리드 캐주얼 핵심 매출원
- **시작 패키지 / 성장 패키지** — 기간 한정 1회, 전환율 최고
- **광고 제거 구독** (소액 IAS) — 라이트 유저 결제 진입점
- **리워드 광고 일일 한도** (10~20회) → 초과 시 다이아로 추가 시청 (IAA→IAP 전환)

## 설계 단계에서 미리 고민할 포인트
1. **재화 흐름 설계 시점에 광고 보상을 빌트인** — 나중에 끼워넣으면 밸런스 깨짐
2. **첫 결제 트리거 지점** — 보통 첫 3일 안에 "결제하고 싶은 순간"이 필요 (예: 실패 직후 재도전 광고/결제)
3. **하드 모드 진입 시점** — IAP 압박 적기. 일반 클리어 후 자연스럽게 패키지 노출

## 보상 / 실패 정책 (기획서 기준)
- 클리어 시 금화 산정:
  ```
  유닛 처치 점수 + 클리어 시간 점수 + 스테이지 클리어 점수
  + 획득 경험치 점수 + 이벤트/유료 보너스
  ```
- 실패 시: 기본 보상 없음 (광고로 재도전 가능)

## 다음 작업 (재무 밸런스)
C/D 완료 후 경제 밸런스 단계에서:
- 광고 시청 N회 유저 vs 결제 유저 성장 곡선 분리 시뮬레이션
- 일일 무료 보상 한도
- 첫 결제 패키지 가격 설정
