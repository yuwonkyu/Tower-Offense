# 14. 유닛 우선타깃 시스템

## 기본 룰
**모든 유닛의 기본 우선타깃 = 공격 범위 내 가장 가까운 적**

이 위에 유닛별 **우선 타깃 보정**이 적용됨.

## 유닛별 우선타깃 보정

### 유저 / 적 유닛 공통

| 유닛 | 우선타깃 보정 |
|---|---|
| 방패병 | 기본 (가까운 적) |
| 활병 | 기본 |
| 창병 | 기본 |
| 투석기 | **탱커형 유닛 우선** (방패병/기마병/거인족) |
| 검사 | 기본 |
| 하급/중급/상급 마법사 | 기본 |
| 암살자 | **원거리 유닛 우선** (활병/마법사/투석기) |
| 폭탄병 | **밀집된 적 위치** 우선 (광역 효과 극대화) |
| 치유사 | **HP가 적은 아군 자동 회복** (적 우선타깃 없음, 공격 X) |
| 기마병 | **원거리 유닛 우선** (활병/마법사/투석기) |

### 영웅 우선타깃
| 영웅 | 우선타깃 |
|---|---|
| 마루한 | 기본 (가까운 적, 광역 처리) |
| 미르 | 기본 (가장 가까운 단일) |
| 노을 | **HP가 낮은 적 우선** (처형형) |
| 적 기사 | 기본 |
| 적 마법사 | 기본 |
| 적 팔라딘 | **HP가 낮은 아군 우선 회복**, 적 공격은 기본 |

## 적용 우선순위 (다중 조건 시)
1. 강제 우선 표적 (예: 암살자 → 원거리 우선)
2. 가장 가까운 적
3. 범위 밖이면 추격

> 우선표적이 범위 밖에 있으면 → 기본(가까운 적)으로 폴백

## 디자인 의도
- 빌드 다양성 강화 — "원거리 유닛 보호용 탱커" 같은 전략 가능
- 적 측 우선타깃은 유저에게 위협 요소로 작용 — 활병 비중 높은 빌드 = 암살자/기마병에 취약
- 치유사는 적 측에서 처치 우선 표적이 되도록 다른 유닛들의 우선타깃에 포함 가능 (추후 패치 시 고려)
