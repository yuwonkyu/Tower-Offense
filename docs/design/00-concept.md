# 00. 게임 컨셉 & 전체 기획

## 한 줄 소개
자동 생성되는 공성 유닛과 영웅 스킬, 로그라이크 카드 선택을 활용해 제한 시간 안에 적 타워를 파괴하는 실시간 공성 전략 게임.

## 영감
- 워크래프트3 유즈맵 "타워 서바이벌"의 **역방향** — 타워를 부수는 쪽
- 모바일 하이브리드 캐주얼 (Archero, Survivor.io, 뱀파이어 서바이벌)

## 핵심 코어 루프
```
스테이지 전투
→ 적 유닛 처치 & 경험치 획득
→ 레벨업 시 카드 선택
→ 타워 파괴
→ 보상 획득
→ 유닛/영웅 강화
→ 다음 스테이지 도전
```

## 플레이 흐름
1. 스테이지 시작
2. 메인 영웅 등장
3. 공성 유닛 자동 생성
4. 적 유닛 / 구조물 제거 → 경험치 획득
5. 레벨업 시 카드 선택 (로그라이크 빌드 성장)
6. 제한 시간 내 타워 파괴 시 클리어 / 실패 시 게임 오버

## 시간 / 조작
- **스테이지 제한 시간**: 5분 또는 10분 (테스트 후 결정)
- **유저 직접 조작**: 영웅 스킬, 카드 선택
- **자동 진행**: 유닛 생성, 유닛 전투, 타워 방어

## 배속 시스템
| 배속 | 조건 |
|---|---|
| x1 | 무료 |
| x2 | 무료 |
| x4 | 유료 또는 광고 |

5분 스테이지 기준 x4 시 약 1분 15초 (카드 선택 시간 제외)

## 카드 / 빌드 시스템 (요약)
- **슬롯 8개** (유닛 특성 + 글로벌 버프 혼합)
- 같은 카드 최대 5스택 (Lv1~5)
- 카드 풀 고갈 시 → 골드 / 다이아 **획득용** 카드 등장
- 등급: 일반 / 고급 (희귀도)

## 난이도
- **일반 모드** — 기본 진행
- **하드 모드** — 일반 10스테이지 클리어 시 개방. 난이도 2배, 보상 2배, 카드 선택지 +1, 랜덤 디버프

## 스테이지 구조
- **10 스테이지마다** 신규 맵 / 타워 / 적 영웅 / 신규 유닛 조합 / 트랩 변경

## 적 측 (방어)
- 타워 HP / 방어력 / 방어 유닛 / 구조물 배치 단계별 강화
- 적 공성 영웅: 10스테이지마다 변경, 카드 선택 없음 (대신 스킬 쿨감 / 유닛 생성속도 증가)
- 적 공성 유닛: 유저와 동일, 능력치만 차이

## 보상
```
최종 금화 =
  유닛 처치 점수
+ 클리어 시간 점수
+ 스테이지 클리어 점수
+ 획득 경험치 점수
+ 이벤트/유료 보너스
```

## 메타
- 업적 / 퀘스트 / 수집 도감 / 출석 → **다이아** 지급

## 별도 모드 (보류)
- **타워 모드** — 30분 / 일일 제한 / 끝없이 몰려오는 유닛 방어

## 강점 분석
- 자동 전투 + 직접 개입 구조
- 로그라이크 카드 조합 → 빌드 다양성
- 짧은 플레이 타임 + 반복 친화적
- 모바일 배속 구조와 잘 맞음
