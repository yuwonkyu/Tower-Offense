# 15. 종족 시스템 비전 (장기 로드맵)

## 출시 시점 (1차)
- **인간 종족 단독 30 스테이지**
- 31+ = "업데이트 중" 표시
- 사용자 반응 보고 종족 패치 순차 진행

## 8 종족 체계 (장기 로드맵)

### 종족 컨셉

| 종족 | 컨셉 | 핵심 키워드 |
|---|---|---|
| **인간** | 균형 | 다양한 직업 (기사/마법사/팔라딘) |
| **마족** | 비균형, 극과 극 | 흡수: 마물, 언데드, 다크엘프 |
| **엘프** | 자연 친화 (4원소) | 물/불/바람/흙 + 체력재생, 흡수: 요정 |
| **드워프** | 기술 + 화력 + 높은 방어 | 흡수: 소인족 |
| **용족** | 기본 스탯 압도적 | 진화의 정점, 유일존재 컨셉 |
| **수인족** | 변신 기믹 | 시간 경과 시 변신 → 스펙업 + 스킬 사용, 흡수: 늑인/어인족 |
| **거인족** | 초탱커, 광역 분쇄 | 이속 느리지만 강함 |
| **천계** | 신성, 회복, 버프 | 빠른 공/이속, 회복/버프 위주 |

### 상극 구도

| 대립 | 내러티브 |
|---|---|
| **인간 vs 마족** | 삶 vs 죽음 (필멸 vs 언데드/마물) |
| **엘프 vs 드워프** | 자연 vs 기술 |
| **용족 vs 수인족** | 정점(우월감) vs 진화(열등감) |
| **거인족 vs 천계** | 타이탄 vs 신화의 영웅들 |

> 8종족이 4쌍의 라이벌 구도. 후속 컨텐츠로 "동맹전" 같은 시스템 가능.

## 컨텐츠 확장 규모

| 항목 | 규모 |
|---|---|
| 총 스테이지 | **240** (종족당 30) |
| 총 유닛 | **64~80** (종족당 8~10) |
| 총 영웅 | **24** (종족당 3) |
| 총 디버프 종류 | **8** (종족당 1개씩) |

## 종족별 디버프 매핑 (1차 안)

| 종족 | 디버프 | 효과 |
|---|---|---|
| **인간** | 덫 | 지속 데미지 (DOT) |
| **마족** | 저주 | 스탯 감소 |
| **엘프** | 얽힘 | 슬로우 |
| **드워프** | 폭발 트랩 | 스턴 (혼란) |
| **용족** | 공포 | 행동 제한 (잠깐 패닉) |
| **수인족** | 출혈 | 지속 데미지 변종 (강한 DOT) |
| **거인족** | 위압 | 공격력 ↓ |
| **천계** | 회복 차단 | 힐 봉인 / 침묵 |

## 종족 활용 후속 컨텐츠 (잠재력)

- 종족별 길드 시스템
- 종족 동맹전 (PvP 또는 협동)
- 종족 vs 종족 PvE 스테이지
- 종족 스토리 모드 (소설화 / RPG 진행)
- 시리즈 게임 — Tower-Offense 2 / 외전 가능

## 종족 추가 패치 순서 (추천)

1. 1차: **인간** (출시)
2. 2차: **마족** (인간의 첫 적수, 자연스러운 스토리)
3. 3차: **엘프** vs **드워프** (동시 또는 순차)
4. 4차: **천계** vs **거인족**
5. 5차: **수인족** vs **용족** (최종)

각 종족 패치 = 30 스테이지 + 유닛 8~10 + 영웅 3 + 디버프 1.
