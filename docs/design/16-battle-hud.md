# 16. 전투 화면 HUD 레이아웃 (확정)

> 세로(Portrait) 모드 기준. WC3 타워 서바이벌 UI 스타일 참고.

## 전체 구조 (위 → 아래)

```
┌─────────────────────────────────────────┐
│ [적 영웅 이름]  [적 HP 바 ████████]  [⚙] │  ← 상단 바
│                        [08:23 시간]      │
│                        [x2 배속]         │
├─────────────────────────────────────────┤
│                                         │
│          ( 적 타워 원형 )                │  ← 전투 영역
│                                         │
├─────────────────────────────────────────┤
│ [영웅 아이콘] [Lv.n 닉네임] [HP ████] [●]│  ← 하단 패널
│              [□□□□□□□□] EXP n/n         │
├─────────────────────────────────────────┤
│ [══════ 아군 경험치 바 (파란색) ══════]  │  ← EXP 바
└─────────────────────────────────────────┘
```

---

## 상단 바

| 요소 | 위치 | 설명 |
|---|---|---|
| 적 영웅 이름 | 좌상단 | 현재 스테이지 적 영웅 (예: 기사) |
| 적 타워 체력 바 | 풀 넓이 (좌측 영웅명 옆 ~ 우측) | 빨간색, HP n/n 숫자 우측 표시 |
| 설정(메뉴) 버튼 | 우상단 모서리 | 체력바 오른쪽 끝 사각형 아이콘 |
| 게임 남은 시간 | 오른쪽 세로 스택 1번 | 설정 버튼 아래, 황금색 칩 |
| 게임 배속 버튼 | 오른쪽 세로 스택 2번 | 시간 칩 아래, 탭 시 x1→x2→x4 순환 |

- 배속 초기값: 플레이어의 마지막 선택값 유지
- x1, x2: 무료 / x4: 유료 또는 광고 시청

---

## 전투 영역

- 배경: 2.5D 평면 (원근감 최소)
- 적 타워: **원형 영역** — 중앙 고정
  - 타워 HP % 에 따라 외관 4단계 변화 (100 / 60 / 30 / 0%)
  - 프로토타입: 테두리 색상으로만 구현
- 영웅: 작은 원형 아이콘으로 표시, 자유 이동
- 유닛: 영웅 360° 주변 자동 생성

---

## 하단 패널

### Row 1 (영웅 정보)

| 요소 | 위치 | 설명 |
|---|---|---|
| 영웅 아이콘 | 패널 좌측 세로 꽉 채운 사각형 | 영웅 이미지 표시 |
| Lv.n | 아이콘 오른쪽 상단 배지 | 현재 영웅 레벨 |
| 플레이어 닉네임 | Lv 배지 옆 | 플레이어 이름 (영웅 이름 아님) |
| 아군 영웅 체력 | 닉네임 우측 n/n + 초록 바 | 현재 / 최대 HP |
| 스킬 버튼 | 패널 우측 끝 원형 | 원형 테두리 = 쿨다운 타이머 (LoL 스타일) |

- 영웅 사망 시: 아이콘 위에 부활 카운트다운 오버레이

### Row 2 (카드 + EXP)

| 요소 | 위치 | 설명 |
|---|---|---|
| 선택된 카드 아이콘 8칸 | 영웅 아이콘 옆 ~ 우측 | 작은 사각형, 미획득 슬롯은 점선 |
| EXP n/n | 카드 줄 우측 끝 정렬 | 현재 인게임 경험치 수치 |

---

## 맨 하단 — 아군 경험치 바

- 풀 넓이, 파란색
- 현재 레벨 진행도 표시
- 레벨업 시 카드 선택 화면 트리거

---

## 스킬 버튼 상세

- 원형 버튼 한 개 (스킬 1개 — 추후 영웅 추가 시 확장 가능)
- 테두리: 쿨다운 링 (0% → 100% 시계 방향, LoL 스타일)
- 쿨다운 중: 반투명 + 남은 초 표시
- 준비됨: 밝은 색 + 가벼운 이펙트

---

## 카드 선택 화면 (레벨업 트리거)

- 롤토체스(TFT) 스타일 — 카드 3장 중 1장 선택
- 중앙 상단: 30초 카운트다운 타이머
- 미선택 시: 3장 중 랜덤 자동 선택
- 다이아 소모: 리롤(새 카드 3장) / 카드 +1장 추가 표시

---

## 스테이지 종료 정산 화면

전투 종료(승리 / 패배) 후 표시:
- 처치한 유닛 수
- 사망 횟수
- 획득 경험치 총합
- 획득 금화
- 클리어 시간
- 최종 도달 레벨
- 보상 x2 광고 버튼
