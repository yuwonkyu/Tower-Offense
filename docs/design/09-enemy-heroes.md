# 09. 적 영웅 (F-2)

## 기본 룰
- **타워 위에 고정** — 이동 X, 타워 위에서 공격/스킬 발사
- **HP = 타워 HP와 동기화** — 영웅을 따로 죽일 수 없음 (시각은 연출용)
- **카드 선택 없음** — 대신 스테이지별 자동 성장 (HP/공/스킬쿨감/유닛 생성속도)
- 10스테이지마다 영웅 교체 → 새 컨셉 / 새 스킬
- **인간 종족 영웅 3종** (1~30 스테이지)

## 영웅별 컨셉 원칙
| 영웅 | 역할 |
|---|---|
| 1번 영웅 | **종족 컨셉 대표** — 종족의 얼굴 (미니 유닛으로도 등장) |
| 2번 영웅 | **종족 비전 영웅** — 종족의 지향점 (인간 = 지식 탐구 = 마법사) |
| 3번 영웅 | **종족 특성 종합** — 1번 + 2번 결합형 (인간 = 기사 + 마법 = 팔라딘) |

## 1번 기사 (1~10 스테이지)
**컨셉**: 인간 종족의 얼굴. 정통파 균형형. 유저 학습 단계.

| 항목 | 값 |
|---|---|
| 공격력 | 25 |
| 방어력 | 30 |
| HP | 200 (타워 동기화) |
| 사거리 | 2 (검기/투척 연출) |
| 공속 | 1.0 |
| 공격범위 | 2 (광역) |

**스킬: 성주변 휩쓸기**
- 반경 5 광역 / 공격력 120% 피해 / 쿨 20초
- 연출: 성 주변에 거대한 검기 회전

> 25 스테이지부터 **기사 미니보스**로 잡몹화 등장 (다운그레이드 버전).

## 2번 마법사 (11~20 스테이지)
**컨셉**: 인간의 비전 — 지식 탐구. 광역 마법 폭격.

| 항목 | 값 |
|---|---|
| 공격력 | 30 |
| 방어력 | 10 |
| HP | 220 (타워 동기화) |
| 사거리 | 18 (장거리 마법) |
| 공속 | 0.8 |
| 공격범위 | 1 |

**스킬: 필드 랜덤 메테오**
- 5발 / 발당 공격력 200% / 반경 3 / 쿨 30초

> 27 스테이지부터 **마법사 미니보스**로 잡몹화 등장 (다운그레이드 버전).

## 3번 팔라딘 (21~30 스테이지)
**컨셉**: 기사 + 마법(신성력) 결합. 인간 종족 특성 종합 — 엔드게임 보스.

| 항목 | 값 |
|---|---|
| 공격력 | 35 |
| 방어력 | 25 |
| HP | 240 (타워 동기화) |
| 사거리 | 3 (성스러운 검 / 신성 광역) |
| 공속 | 1.2 |
| 공격범위 | 2 (광역) |

**스킬 1: 신성 광역 데미지**
- 반경 6 광역 / 공격력 180% / 쿨 25초
- 효과: 적 유닛 / 영웅에 큰 피해

**스킬 2: 회복 오라 (패시브)**
- 반경 5 내 아군(적 유닛) HP/초 회복 = 자신 공격력 × 0.3

**스킬 3: 무적기 (액티브)**
- 발동 시 5초간 무적
- 쿨 60초 (타워 HP 50% 이하 시 1회 자동 발동)

## 30 스테이지 최종 보스 특별 룰

- **팔라딘이 타워에서 나와 직접 전장에 등장**
- **1분 / 3분 시점에 2회 등장** (5분 게임 기준)
- 처치 EXP: **100** / 회

> 일반 등장 시간 외엔 타워 위에 있음. 등장 시 보스 위치는 타워 정면.

## 스테이지별 영웅 성장 (자동, 카드 X)

| 항목 | 1번 기사 | 2번 마법사 | 3번 팔라딘 |
|---|---|---|---|
| HP 증가 | +20/스테이지 | +30/스테이지 | +50/스테이지 |
| 공격력 증가 | +2/스테이지 | +3/스테이지 | +4/스테이지 |
| 스킬 쿨감 | -0.5초/스테이지 | -1초/스테이지 | -1초/스테이지 |
| 유닛 생성속도 | +5%/스테이지 | +5%/스테이지 | +5%/스테이지 |

## 영웅 위치 / 행동

- 1번 기사: 타워 정면 (검기 투척, 광역 스킬)
- 2번 마법사: 타워 후면 (장거리 메테오)
- 3번 팔라딘: 타워 정면 (신성 광역) — 30 스테이지 한정 1분/3분 등장

기본적으로 **타워에서 이동 안 함**. 30스테이지 팔라딘 등장 시점은 특별 규칙.
