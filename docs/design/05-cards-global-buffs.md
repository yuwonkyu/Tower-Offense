# 05. 카드 시스템 — 글로벌 버프 카드

## 규칙
- **슬롯 8개** (유닛 특성 + 글로벌 버프 혼합 카운트)
- 같은 카드 5번 뽑으면 Lv1 → Lv5
- 등급: **일반** / **고급**
- **적용 범위**: 기본은 "전체 아군 (영웅 + 모든 유닛)", 카드별 표기

## 핵심 설계 결정
- **모든 카드는 5렙 한도** (무한 스택 X) — 유닛 생성속도 포함
- **경험치 카드는 일반 등급 유지** — 초반 빌드 가속용
- **골드 획득 증가** 추가 — 하이브리드 캐주얼 경제 보강
- **영웅 부활 시간 감소** 추가 — 영웅 의존 빌드 보강
- **불굴** 카드로 버서커 즉사 위험 해소

## 카드 풀 고갈 시 대체 카드
- **골드 카드** — 즉시 골드 획득
- **다이아 카드** — 낮은 확률 등장, 즉시 다이아 획득

> 빌드 강화가 아닌 **재화 획득용** 카드.

## 카드 풀 전체 규모
- 유닛 특성 카드: **25장** (5유닛 × 5)
- 글로벌 버프 카드: **17장**
- **총 42장**, 스택 포함 시 등장 가능 횟수 = 42 × 5 = **210회**
  - 슬롯 8개 한정으로 인해 실제 선택은 약 40회 내외 예상
  - 풀 고갈 시점: 매우 후반 (의도된 후반 페이즈 전환)
