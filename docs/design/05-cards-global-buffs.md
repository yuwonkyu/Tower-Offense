# 05. 카드 시스템 — 글로벌 버프 카드 (작업 중)

## 규칙
- **슬롯 8개** (유닛 특성 + 글로벌 버프 혼합 카운트)
- 같은 카드 5번 뽑으면 Lv1 → Lv5
- 등급: **일반** / **고급**
- **적용 범위**: 기본은 "전체 아군 (영웅 + 모든 유닛)", 카드별 표기

## 결정 사항 (확정)
- **불굴** 카드로 버서커 즉사 위험 해소

## 미정 (확정 필요)
- 위 수치 OK?
- 추가 후보: 골드 획득 증가, 다중 타격(스플래시), 마나/스킬 게이지 추가 회복, 첫 처치 시 즉시 부활 등
- 유닛 생성속도 증가 최대 스택 한도?
- 경험치 카드를 일반 vs 고급 어디에 둘지

## 카드 풀 고갈 시 대체 카드
- **골드 카드** — 즉시 골드 획득 (인게임 화폐)
- **다이아 카드** — 낮은 확률 등장, 다이아 획득

> 빌드 강화가 아닌 **재화 획득용** 카드.
