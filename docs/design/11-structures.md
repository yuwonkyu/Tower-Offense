# 11. 구조물 시스템 (F-4)

## 기본 룰
- **모두 파괴 가능** — 유닛처럼 HP 보유
- **처치 시 경험치 보상**
- **스테이지별 컨셉 형성** — 배치/종류로 맵 변화
- 방어 오브젝트(공격형 구조물) ❌ (제외)

## 구조물 종류

### 성벽 (타워 주변 고정)
- **배치**: 타워 4방향 고정 (방위별 1~2개)
- **역할**: 타워 직접 공격 차단 — 부숴야 진입 가능
- **HP**: 200
- **방어력**: 5
- **처치 경험치**: 5

### 바리케이트 (맵 전체 랜덤)
- **배치**: 맵 전체에 랜덤 N개 (스테이지마다 위치 변화)
- **역할**: 동선 방해, 학살 루트 변화
- **HP**: 80
- **방어력**: 0
- **처치 경험치**: 3

### 트랩 (타워 주변 반경 내 랜덤)
- **배치**: 타워 반경 내 랜덤 N개
- **역할**: 유저 유닛/영웅 접근 시 피해 + CC
- **HP**: 30
- **방어력**: 0
- **처치 경험치**: 1
- **발동 효과**: 공격력 80% 피해 + 1초 기절, 1회 발동 후 소멸

## 스테이지별 스케일

### 구조물 수량 (스테이지별)
| 스테이지 | 성벽 | 바리케이트 | 트랩 |
|---|---|---|---|
| 1~5 | 2개 | 3개 | 2개 |
| 6~10 | 4개 | 5개 | 4개 |
| 11~15 | 4개 | 7개 | 6개 |
| 16~20 | 4개 | 9개 | 8개 |
| 21~25 | 4개 | 12개 | 10개 |
| 26~30 | 4개 | 15개 | 12개 |

### 구조물 HP 스케일
- HP × (1 + 0.1 × 스테이지)
  - 예: 30 스테이지 성벽 HP = 200 × (1 + 0.1 × 30) = 800

### 처치 경험치 스케일
- 기본 × 1.0 → 1.5 (30 스테이지 선형)

## 소환물 (적 영웅 스킬/패시브 소환)
- **출처**: 모두 타워(성)에서 생성
- **예시**: 엘프궁수 패시브 "덫 소환" — 8초마다 타워 주변에 덫 생성
- 시각적 일관성: "성 = 적 모든 것의 출처"

## 디자인 의도
- 구조물은 경험치 보너스 + 맵 컨셉 동시 담당
- **스테이지마다 다른 배치 = 매판 다른 동선**
- 후반 스테이지 = 트랩/바리케이트 밀집 = 학살 동선 의식적 설계 강제
- 구조물 처치는 빌드 가속 (경험치) → 유저 진행 보상감
