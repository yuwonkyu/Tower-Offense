# 01. 전투 화면 & UI

## 화면 구성
- **시점**: 2.5D
- **중앙**: 적 타워
- **유닛 표현**: 프로토타입 단계에선 **원형 UI**로 진행. 정식 아트는 추후 적용

## 연출 원칙
- **이펙트는 최소화** — 큰 이펙트 없이 깔끔하게
- **공격 모션 사운드** 중심
- 타워 타격 시 **타격감** 강조 (사운드 + 가벼운 화면 셰이크)

## 타워 외관 단계 변화
체력 % 에 따라 외관 단계 변화:

| HP % | 단계 |
|---|---|
| 100% | 정상 |
| 60%  | 일부 균열 |
| 30%  | 심한 손상 |
| 0%   | 파괴 |

- **프로토타입**: 타워 테두리 색을 **빨강 → 흰색**으로 변화 (체력바 색상과 연동)
- **출시 시점**: 실루엣 자체가 단계별로 달라지도록 아트 작업

## 승리 / 패배
- **승리**: 타워 파괴 시 승리 이펙트 + "VICTORY" 텍스트
- **패배**:
  - 타워 파괴 실패 (시간 종료)
  - 기본 보상 없음
  - 광고 시청 시 재도전 가능
